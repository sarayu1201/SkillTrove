# SkillTrove Platform

A comprehensive learning platform with professional and student portals, featuring gamified quizzes, community hub, and career development tools.

## 🌟 Features

### 🔐 Dual Login System
- **Student Portal**: Personalized learning dashboard with gaming elements
- **Professional Portal**: Career-focused dashboard with industry insights

### 🎮 Gaming Environment Quizzes
- **Student Quiz**: Neon-themed gaming arena with particle effects
- **Professional Quiz**: Executive assessment with scenario-based questions

### 🌐 Platform Pages
- **Community Hub**: Interactive discussions and networking
- **Projects Showcase**: Portfolio display with filtering and search
- **Internship Portal**: Job opportunities with company listings
- **About Us**: Team information and company values

## 📁 File Structure

### Core Pages
- `index.html` - Main home page with login options
- `about.html` - About us page with team members

### Authentication
- `student-login.html` - Student login page
- `professional-login.html` - Professional login page

### Dashboards
- `Aimentoring.html` - Student dashboard (enhanced)
- `professional-dashboard.html` - Professional dashboard

### Gaming Quizzes
- `student-quiz.html` - Gaming-style student quiz
- `professional-quiz.html` - Professional assessment arena

### Feature Pages
- `community.html` - Community hub
- `projects.html` - Projects showcase
- `internships.html` - Internship portal
- `aimodel.html` - AI model page (existing)

## 🚀 Getting Started

1. **Open `index.html`** in your web browser
2. **Choose your portal**: Student or Professional
3. **Explore the features**: Quizzes, Community, Projects, Internships
